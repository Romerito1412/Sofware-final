# Sistema de Control de Gastos y Ahorros - Residencia Emiliani

Proyecto final de Software. Permite registrar estudiantes, controlar sus gastos
por categoría (Comida, Transporte, Salidas, Estudios) y administrar metas de
ahorro. Toda la información se guarda en archivos JSON para que persista entre
ejecuciones.

El programa tiene varias opciones. La primera necesita que le ingreses un ID y un Nombre valido. La opciòn 3 te muestra los registros
de un estudiante individual o de todos. La opciòn 4 te permite borrar un estudiante por su ID. La opciòn 5 termina todo
